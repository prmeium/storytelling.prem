# storytelling.prem

Prem Gohel’s personal storytelling page. A simple, responsive, text-first site with updated November 2026 copy.

## Files

- `index.html` — story, navigation and contact links
- `style.css` — responsive typography and layout
- `assets/fonts/` — self-hosted Inter and its SIL Open Font License
- `assets/favicon.svg` — site icon

No framework, build step, analytics, cookies, or third-party JavaScript is required.

## GitHub Pages

Deploy `main` from `/ (root)` in Settings → Pages. `.nojekyll` keeps deployment static.

## Content

Adapted from Prem’s original personal page at https://mmm.page/premmm/info and his current professional work. Visual direction: the minimal, conversational personal site at https://farza.com/. All story copy is original to Prem’s page; no Farza biography, media, or source code is reused.

Keep the dated “now” section updated when Prem’s role or availability changes.
